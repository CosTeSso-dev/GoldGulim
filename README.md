# «Гранат» — сайт ювелирного магазина в Нукусе

Сайт: **https://costesso-dev.github.io/Opalia/**

Статический сайт-каталог на русском и узбекском языках: каталог с фильтрами и поиском,
карточка товара, корзина и оформление заказа через Telegram или WhatsApp.
Сервер, база данных и сборка не нужны — это обычные HTML, CSS и JavaScript.

## Как открыть

Откройте `index.html` в браузере. Для проверки «как на хостинге» можно запустить
локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Что где менять

| Что изменить | Файл |
| --- | --- |
| Телефон, WhatsApp, Telegram, адрес, валюта, язык по умолчанию | `js/config.js` |
| Товары, цены, категории, фото | `js/products.js` |
| Тексты сайта на русском и узбекском | `js/i18n.js` |
| Цвета, шрифты, оформление | `css/style.css` (цвета — в начале файла, блок `:root`) |
| Фото товаров | папка `images/products/` |
| Иконка сайта и картинка для превью ссылки | `images/favicon.svg`, `images/apple-touch-icon.png`, `images/og-image.png` |

### Обновить каталог из Telegram-канала

Каталог собирается из постов канала [t.me/granatnukus](https://t.me/granatnukus)
скриптом (нужен Python 3, больше ничего ставить не надо):

```bash
python3 tools/import_telegram.py
```

Скрипт читает посты, определяет по тексту вид изделия, пробу, вес и камни,
скачивает фото в `images/products/` и пересобирает `js/products.js`.
Цены и отметки «нет в наличии», которые вы уже вписали, сохраняются.
Новые посты с описанием в формате «Проба 585, грамм 5,5, серьги "Бирюза"»
попадут в каталог автоматически. Посты только с фото (без текста) скрипт
пропускает и перечисляет их номера в конце.

### Добавить товар вручную

1. Положите фото в `images/products/` (лучше квадратные, от 800×800 px, формат JPG или WebP).
2. В `js/products.js` скопируйте любой блок `{ ... }` внутри `PRODUCTS` и поменяйте поля.
   У каждого товара должен быть свой `id`.
3. Перевод на узбекский пишется в блоке `uz: { ... }`. Если его не заполнить,
   на узбекской версии будет показан русский текст.

### Добавить категорию

В `js/products.js` добавьте строку в `CATEGORIES`, например
`watches: { ru: "Часы", uz: "Soatlar" },` и укажите `category: "watches"` у нужных товаров.

## Как работает заказ

Покупатель добавляет товары в корзину (она сохраняется в его браузере) и нажимает
«Оформить в Telegram» или «Оформить в WhatsApp». Открывается чат с магазином,
в котором уже написан список товаров с количеством и итоговой суммой —
остаётся только отправить сообщение.

Кнопка «Заказать в 1 клик» в карточке товара делает то же самое для одного
товара и добавляет к сообщению ссылку на него.

## Полезные ссылки

- `index.html?lang=uz` — сайт сразу на узбекском (`?lang=ru` — на русском).
- `index.html#product-3` — сразу открывает товар с `id: 3`. Такую ссылку
  копирует кнопка «Скопировать ссылку» в карточке товара.

## Публикация на GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**,
   ветку с сайтом и папку `/ (root)`, нажмите **Save**.
3. Через минуту-две сайт будет доступен по адресу вида
   `https://<имя-пользователя>.github.io/<репозиторий>/`.

### Свой домен

Домен (например, `granat.uz`) покупается у регистратора и связывается
с GitHub Pages в два шага:

1. В панели регистратора, в настройках DNS домена, добавьте записи:
   - четыре записи типа **A** для самого домена (`@`):
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись **CNAME** для `www` со значением `<имя-пользователя>.github.io`.
2. В репозитории в **Settings → Pages → Custom domain** впишите домен,
   нажмите **Save**, а когда проверка пройдёт — включите **Enforce HTTPS**.

Изменения DNS вступают в силу от нескольких минут до суток. Старый адрес
`github.io` после этого автоматически перенаправляет на новый домен.

## Перед запуском

- [ ] Указать настоящие контакты в `js/config.js`
- [ ] Скачать фото изделий: `python3 tools/import_telegram.py`
- [ ] Проверить цены и описания в `js/products.js`
- [ ] При желании заменить `images/og-image.png` — эта картинка показывается,
      когда ссылкой на сайт делятся в мессенджерах
- [ ] При переходе на свой домен заменить адрес `costesso-dev.github.io/Opalia`
      в `index.html` (строки `og:url` и `og:image`) — по ним мессенджеры
      показывают превью ссылки
